# Logic Number Guesser

A small Python command-line game that generates a number puzzle using random clues.

## How to play

The game gives clues about a number between 1 and 100: whether it’s even or odd, a minimum threshold, and two divisibility rules. Enter a number that matches all the clues.

There may be more than one valid answer. If your guess is incorrect, the game shows the valid answer or answers and lets you try again.

## Run the game

You’ll need Python 3. From the project folder, run:

```bash
python "Logic puzzle game.py"
```

The game uses only Python’s standard library; no extra packages are needed.
